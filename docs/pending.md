# Отложенные задачи TaskBuddy

Здесь записаны задачи, которые решено сделать позже: что именно отложено, почему и на каком этапе
к нему вернуться. Идеи для будущих версий лежат в «Требованиях к TaskBuddy» (раздел «На будущее»),
здесь их не повторяем.

Когда задача сделана, она удаляется из файла в том же PR, где сделана.
